How this works

This admin page is separate from the public site. It reads and writes files in GitHub, then Render can deploy the new commit.

The token is never committed to the project. By default it is kept only for this browser session.

  • Use a fine-grained GitHub token.
  • Give access only to RAYMAN720/atelier-koka-site.
  • Repository permissions: Contents: Read and write.

Workflow

Recommended editing flow

  1. Connect with a GitHub token for the public website repo.
  2. Upload new tattoo, flash, drawing, or studio images in Images.
  3. Open Pages, choose a page, replace image slots, and edit text.
  4. When English source text changes, update matching entries in FR Text.
  5. Save changes. Each save creates a GitHub commit for Render to deploy.

For bigger redesigns, keep using Codex. This control room is meant for everyday content changes.
