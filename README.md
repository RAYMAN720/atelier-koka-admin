# Atelier Koka Control Room

Separate static admin app for managing the public Atelier Koka website.

## What it edits

- Repository: `RAYMAN720/atelier-koka-site`
- Branch: `main`
- Images: files in `assets/`
- Pages: HTML files such as `index.html`, `contact/index.html`, and artist/archive/date pages
- French dictionary: the `translations.fr` object inside `script.js`

## GitHub token

Use a fine-grained GitHub token with access only to `RAYMAN720/atelier-koka-site`.

Required repository permission:

- Contents: read and write

The token is entered in the browser and is not stored in this repository.

## Render

This is a static site. Render settings:

- Type: Static Site
- Build command: blank
- Publish directory: `.`
